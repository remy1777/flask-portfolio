# Reem Mazen Khrfan - Portfolio

A personal portfolio website built with Python and Flask. It presents my profile, technical skills and Python projects, with a horror-themed design.

## Features
- Flask routes and Jinja templates
- Projects section rendered dynamically from a Python list
- Responsive CSS design using Flexbox and Grid

## Run locally
1. Create and activate a virtual environment: python -m venv venv then venv\Scripts\activate
2. Install dependencies: pip install -r requirements.txt
3. Start the server: flask run
4. Open http://127.0.0.1:5000
